# Image placeholders
Replace the three SVG sample artworks and profile-placeholder.svg with your own images.

- profile-placeholder.svg: replace with a portrait photo (keep this filename or update the img src in index.html).
- gallery-01.svg, gallery-02.svg, gallery-03.svg: replace with gallery images. Update the matching image src and data-full paths if you change filenames.
- Use appropriately sized, optimized images and meaningful alt text. Do not include images you do not have rights to use.
